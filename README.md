# Ember: scene blocking decks

Built pages only. Each deck steps through a scene of Ember, a game in progress, one beat at a time, as blocking previs:
where everyone stands and where the camera looks, not the finished game. The site is served by GitHub Pages from this
branch; every page asks search engines not to index it.

Every page is locked: what's stored here is encrypted, and opens in the browser only with the password Liam gives his
friends. Without it the files are noise.

Nothing here is edited by hand. The decks are built from the game's own repository and pushed here on Liam's word.
