# Small Hours: Field Book

Built pages only: the built pages of "Small Hours: Field Book", its scene decks and its books. Each scene deck steps
through a scene of Ember, a game in progress, one beat at a time, as blocking previs: where everyone stands and where
the camera looks, not the finished game. Each book is a page per entry, read from the game's design. The site is served
by GitHub Pages from this branch; every page asks search engines not to index it.

Every page is locked: what's stored here is encrypted, and opens in the browser only with the password Liam gives his
friends. Without it the files are noise.

Nothing here is edited by hand. The decks and books are built from the game's own repository and pushed here on Liam's
word.
